# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability
reporting, on the **Security** tab of this repository ("Report a vulnerability").
That keeps the report between us until there is a fix. Please do not open a
public issue for anything security-relevant.

A first reply should come within a few days. This is a personal project, not a
staffed product, so please read that as a best effort rather than a commitment.

## No bug bounty

There is no bug bounty and no payment for reports. Contributions are credited in
the release notes if you would like them to be.

## What this project is

This is a **demonstrator**. It has not been validated for production clinical
use, it has no authentication or access control, and it is not hardened for
deployment on a network. It is meant to be run locally, against sample data or
against terminology files you have downloaded yourself.

It contains no patient data and no terminology content. Do not put real patient
data into it.
